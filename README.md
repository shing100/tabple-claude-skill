# Tabple Claude Code Skill

LLM 코드 에이전트(Claude Code 우선)가 [Tabple](https://tabple.com) 의 위키·보드를 컨텍스트로 활용하게 해주는 스킬 패키지.

## 설치

```bash
/plugin marketplace add shing100/tabple-claude-skill
/plugin install tabple
```

Tabple 데스크탑 앱을 쓰고 있다면 설정 화면의 Claude Code 스킬 항목에서 버튼으로 설치할 수도 있다.

설치 후 PAT 발급 가이드 → [skills/tabple/README.md](skills/tabple/README.md)
